# 是男人就飞三次

一款赛璐璐风格的海上街机竞速游戏。“独立竞技”会自动前进，玩家负责转向、漂移和起飞；
“队伍协作”由两名玩家分别控制前进、刹车、倒车和当前能力，在固定分屏里完成三种互补任务。

## 玩法目录

桌面版从玩法目录进入两条并列体验：

- **独立竞技**：原有六艇竞速。争夺名次，完成三飞资格与七飞 Final Station。
- **队伍协作**：本地固定分屏合作。两侧各自驾驶一艘艇，通过互补能力完成三站试航，
  不进入独立竞技排行榜。

队伍协作先经过“按键入座”：键盘左区或任一手柄按左占左侧画面，键盘右区或任一手柄
按右占右侧画面。画面归属确定后，两侧同时选择选手；同一选手不能重复签约。左侧画面
始终属于左席、右侧画面始终属于右席，协作站之间只交换职责，不交换画面和设备。

第一次进入会先分别校准前进、前进中左右转向、刹停、倒车和能力键。完成一次后默认跳过，也可以从
队伍协作入口主动“重玩驾驶校准”。正式试玩包含三站：

1. **锚锤工坊**：锚钉手按住能力键，把实体锚钉压入机构并合拢接收夹爪；冲击锤手蓄力落锤，
   将实体核心打过机械轨道。锚钉没锁牢时核心会偏落入水并原位复位；两次成功后交换工具。
2. **双锁水闸**：一席停在绞盘工位持续收紧钢索、升起实体水闸，另一席穿门，随后互换；末端
   两席共同合拢泊位夹具。
3. **水空协奏**：门控手停在控制台供能并转动控制轮，左右移动真实飞行门；飞行员从发射架起飞
   穿门，落水后两席低速驶入各自泊位并同时确认。

每个工位都会用真实机构动作、流动能量线、蓄力冲击波和进度键帽指向当前责任；玩家不需要靠猜一枚
黄点或蓝点来理解下一步。

工作区的蓝 / 黄光圈是宽阔的停车辅助，不是玩法道具本体。能力键接通机构后会对船体施加真实的
阻尼锚泊力，抑制浪和残余惯性，但不会传送船或替玩家驶入工位。核心落水会在当前拍重新发射，
越线会回到当前目标前，飞行失败只回到起飞前。通关后可以直接
交换职责重玩。每站保存续玩入口；只有从第一站完成三站才更新最快时间。手机端仍进入独立竞技。

## 独立竞技

每一飞都遵循同一条节奏：

1. **按住漂移键**，让船边的 `BANK` 读条越过黄色刻度。
2. **松开漂移键**，把一格飞行库存存进船边的菱形。
3. **靠近半透明白雾起飞入口时按起飞键**，沿空中航道穿过门。
4. **空中继续用漂移键空刹并转向**，把船压回急弯里的白雾线路。

漂得更久只会让这次水面 `BOOST` 持续更久，不会把一格飞行变成长航程；真正的飞行
库存来自“过黄线后松开”。最多可以存三格，每次水面起飞消耗一格；即使还有多格库存，
同一飞也最多只能再消耗一格续航一次。

正规水面路线上的 checkpoint 浮漂是真实障碍：撞中会损失 20% 速度，把浮标抛起并弹飞鸭子气球；
气球旋转升空后爆成羽毛，浮标落水并稍后归位，不会判负；
菱形升空入口和飞行分支只负责导航，不生成锥体或浮漂。飞行中或高空浪跳不会触发这类撞击。

当前六名选手依次为 `GLM`、`ChatGPT`、`Gemini`、`Kimi`、`Claude` 和 `DeepSeek`；选手卡片会同时显示
对应的中文玩梗名 `唐老杰`、`奥特曼`、`美国豆包`、`杨植麟`、`蓬蓬头`、`梁圣梁子`。英文模型名保留为稳定身份，
开场身份牌和选手电台使用中文玩梗名。前三飞完成后会冻结当前比赛，播放 `男人勋章` 仪式，仪式上可以直接翻开神秘资料片画廊；恢复后继续挑战第四至第七飞。第七
门计分后，普通水面偏航和逆行判定解除，落水后从任意方向穿过可见金门即可完成 Final。
终点按每条船真实穿门的先后顺序结算；停在门前让对手先过，名次也会如实下降。在第七门
之前，漏门、提前落水、偏离空中航道和水面逆行仍然会结束本局。

## 操作

独立竞技操作：

| 设备 | 转向 | 漂移 / 空刹 | 起飞 / 续航 |
| --- | --- | --- | --- |
| 键盘 | `A` `D` 或 `←` `→` | `Shift`（按住） | `Space` |
| 手柄 | 左摇杆或方向键 | `X / Square`，肩键也支持 | `A / Cross` |
| 手机 | 左侧触控区 | 右下 `漂 / 刹` | 右侧上方 `飞` |

队伍协作把一套键盘拆成两个独立虚拟设备：

| 席位 | 前进 / 制动倒车 | 转向 | 当前能力 / 空刹 | 起飞 / 确认 | 返回 |
| --- | --- | --- | --- | --- | --- |
| 键盘左区 | `W` / `S` | `A` `D` | `Left Shift` | `Space` | `Q` |
| 键盘右区 | `↑` / `↓` | `←` `→`，也支持 `J` `L` | `Right Shift`、`K` 或 `Numpad 0` | `Numpad Enter`，也支持 `I` | `Numpad .`，也支持 `U` |
| 每只手柄 | 左摇杆 `↑` / `↓` | 同一根左摇杆 `←` / `→` | `X / Square` | `A / Cross` | `B / Circle` |

协作中的 `Esc` 或任一手柄 `Start` 会同时冻结两侧物理与计时；确认键继续，返回键或暂停层
按钮退出到玩法目录。设备断开也会冻结，重新连接并确认后继续。锤击、锚定、门锁、飞行与碰撞提示
会按所属席位左右定位，连续发动机和音乐保持居中。结算后确认会交换职责重玩，返回键回到玩法目录。
半屏飞行提供轻量航线回正；玩家主动转向时辅助会退让，飞行门和走廊的通过标准不变。

手柄协作移动只认一根左摇杆：上下控制前进 / 制动倒车，左右控制转向，斜向可以同时前进并转弯。
十字键上下仅作为没有可用摇杆时的数字输入备用；`RT` / `LT` 不参与协作移动，也不会出现在游戏内操作提示中。

独立竞技没有加速键，油门会自动保持；队伍协作使用完整的前进、制动和倒车。键盘的 `Shift`
在独立竞技水面是漂移，在协作站是当前能力，进入空中后都是空刹；
手机默认使用触控转向，横屏游玩，竖屏会暂停并提示旋转设备。重力转向是主动选择的
备用模式，不会改变右侧漂移和起飞按钮的位置。手柄漂移有持续震感，每次落水都会
有一次强力震动；体感反馈可以在混音面板整体开关。

第一次在 PC 键盘上开局时，画面会用一条不阻塞操作的短提示告诉你先按住 `Shift`；
第一次真实失败后，才会邀请你开启更完整的逐步驾驶提示。所有提示都可以跳过，且不会
降低物理难度或影响勋章资格。起飞与续航提示卡只在你还没掌握该动作时出现，练会之后就
不再弹出；每飞续航限一次，用完后继续按起飞键不会有第二次效果，画面会直接告诉你本次
续航已用完、剩余库存留给下一飞。

点下 `GO` 后不会立刻把你扔进倒计时：会先锁住输入约 3.6 秒，让六名选手、艇和车手
在海面上完成一段开场亮相。Chromium 如果刚好弹出自己的全屏说明，倒计时还会再等一小段
固定缓冲，让浏览器的提示先退场；这段等待只发生在开局展示，不会改变比赛中的速度或判定。

## 画面、声音与保存

半透明白雾航道表示“可以飞行的空间”，绿色水面线表示“当前推荐的水面路线”。航道会沿真实
路线流动，并在急弯前用形状和方向提前提示，不会接管转向。冲过门后的惯性会保留，
门后回收尾段和水面路线会平滑交接。偏出白雾边缘不会立刻判负：雾气会先被撕裂、
船身被风吹得摇晃并被缓缓带离航道，同时警报与震动逐级增强；只要立刻回正就能
救回来，越飘越深才会失速下坠、判为偏离航道。

六位选手在艇上露脸驾驶，发色、肤色与立绘一致，白色赛服配各自战队色的手套和滚边；
两位女选手分别保留青色发梢 bob 与高马尾轮廓，开场身份牌会明确标出“女将”。
转向时他们会提前看弯，并肩缠斗时会互相转头挥拳挑衅，冲线后敢放开双手庆祝。

强敌完成一段漂亮的连漂后，艇尾会沿用玩家同源的蓝白短尾焰，随真实 BOOST 突发并收束；
漂移蓄力时不会持续冒特效，方便你一眼分清“正在蓄力”和“已经释放”。

艇尾两片主动翼面会跟随真实操作：水面漂移时大幅抬升，转向时左右差动；空中按住空刹后
张角更大，松手会带明显的阻尼回摆。近海的象牙白灯塔是固定视觉地标；当前明亮日间环境下
灯室不发射扫光，不参与赛道、碰撞或路线判定。

背景音乐在第一次明确操作后启动并贯穿本局；`3 · 2 · 1` 使用递减灯光和短促电子音，
`GO` 使用更高一档的非语音起步信号。环境水声目前只保留经过审核的短事件，未审核的
持续噪声不会自行加入。碰撞、落水和触觉反馈会合并同帧事件，不抢断右手漂移手感。

选手、勋章、独立竞技成绩、队伍协作教学与站点、最快时间、资料片浏览记录和驾驶提示偏好都保存在本机浏览器中。资料片画廊
是概念预览，不代表七个资料片已经可玩；当前页面按需加载图片，失败时会显示重试状态。
手机打开截图预览时会先收起游戏按钮；预览页提供明确的“回到游戏”按钮，随时可以退出截图页。
桌面和手机都只在按下 `GO` 时首次请求沉浸全屏，选手切换不会提前弹出浏览器提示；Chrome 的原生
“如何退出全屏”提示属于浏览器界面，网页不能把它关掉，所以开场展示会给它留出缓冲。PC 如果全屏被
系统或用户退出，比赛右上角会出现“恢复全屏”，也可以关闭本局提示；手机则在下一次真实游戏触控时重试。
系统分享若退出全屏，关闭或返回游戏时会立即尝试恢复。

## 开发参与

项目使用 TypeScript 编写游戏逻辑，Vite 启动开发环境并把源码整理成网页，Three.js
负责把船、海面和光影组织成实时 3D 画面，Playwright 则让真实浏览器自动跑完关键验收。
Node.js 只是这些开发、构建和验收工具的运行环境，不是玩家必须安装的游戏引擎。

发布时，Vite 会把开发代码整理成浏览器能直接运行的 JavaScript；Chrome、Safari 等浏览器
各自用内置的 JavaScript 引擎把这些代码跑起来，玩家不需要安装 Node.js 或绑定某一种引擎，
再通过浏览器自带的 3D 绘图能力 WebGL 把画面交给显卡。

它没有套用完整的游戏引擎：船感、海面、赛道与飞行规则都由这些小系统一层层组织，
你看到的效果，来自它们在浏览器里彼此咬合。

```bash
npm run build
npm run verify:smoke
npm run verify:team
```

`verify:smoke` 会在真实浏览器中检查桌面与 `844x390` 横屏手机能启动、画面非空，以及
关键 HUD 不重复、不溢出、不遮挡。`verify:team` 用真实键位完成驾驶校准、锚锤工坊、
双锁水闸和水空协奏，并检查按键入座、输入隔离、失败恢复、交换职责与协作存档。碰撞和音频只在相关改动时运行对应的
`verify:collision`、`verify:audio`。常用
代码位置如下：

- `src/game/`：船体、赛道、飞行、AI、记录。
- `src/core/`：键盘、手柄、手机输入、触觉和固定步进。
- `src/hud/`：选角、HUD、驾驶提示、Final 和资料片画廊。
- `src/audio/`：BGM、事件音效、混音和音频解锁。
- `harness/`：确定性浏览器验收。

每个任务开始都完整阅读 [`AGENTS.md`](AGENTS.md)、[`docs/llmwiki.md`](docs/llmwiki.md)
和 [`docs/development-handoff.md`](docs/development-handoff.md)。改了物理、生命周期、音频
或记录，就运行对应专项 harness；像素改动则保存桌面和横屏手机截图供人工复核。
