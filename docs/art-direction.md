# Board Race 美术需求复盘

- 原始目标很简单：海面要有真实、汹涌、有尺度的大浪，而不是换成更绿、更亮的平面材质。
- 海面升级必须同时处理浪形、浪峰、船体起伏和水面接触；只调颜色、法线或闪点不算完成。
- 尾流不能是两条连续白轨；落水水花必须看得见；开场船体不能沉进动态浪面。
- 船体需要清楚的竞速轮廓、结构层次和速度感，不能只堆小零件。
- 选手需要更自然的重心、关节动作和比赛姿态，不能继续像僵硬卡通剪影。
- 车手定稿方向（2026-08-22 拍板）：露脸不立盔，发色肤色锁定立绘；白帆赛服为主色，
  战队色只给手套、V 背条、膝甲和滚边；关节与衣料同色，禁止异色球关节（机器人感根因）；
  六人呼吸相位必须错开，不许同步木偶。
- 2026-08-22 追拍：并肩互动只留侧头对视，删除单手举起（全员同步举拳读成机械木偶）；
  车手"一团黑"的根因是内部描边整涂细四肢，不是配色——内部描边按视深淡出、只放行硬折边；
  水面浮标是实体可撞飞；引导箭头只在近场出现，远端海面不许有悬浮白三角。
- 2026-08-22 船体与姿势追拍：船尾用高架后掠尾翼（队色主翼+端板鳍+发光尾缘），
  不许低平黑件堆成黑团；车手手套必须真实落在把套上（把位不得超出臂展），肩部反旋转
  抵消驼背保持握把；发型从背面必须可读——全发型后颈发量、bob 及肩帘、长辫过颈，
  禁止泳帽/头盔感。
- 2026-08-28 拍板：删除冲线定格的挥手 / 举臂循环（招手欢呼）。循环式手臂泵动在定格画面上
  读成机械木偶，车手全程保持握把姿势，冲线情绪由镜头与 HUD 承担；并肩挑衅只保留转头对视。
- Gemini 电台不能重复，桌面和移动字幕都要居中、可读且不遮操作与航线。
- 交通锥只允许出现在绿色水面主线的 checkpoint 门；菱形升空入口和飞行分支不得生成任何
  锥体、浮标、黑色投影器或随指引显隐的实体支架。
- 水面荣誉目标只保留浮漂结构和铸造金币；鸭子道具已删除，鸭子的戏剧性交给 checkpoint 浮漂弹飞的真实
  气球，不要再放第二个鸭子标记。金币必须有锯齿边、双层轮缘、清晰罗盘压印和克制的
  金色高光，命中时用环形扩散、碎片飞散和专属拾取卡表达价值。海铃、星标、王冠、彗星不再生成，金币不得放进
  起终点视线或伪装成升空提示；拾取文字固定在顶部安全带，移动端还必须避开触控热区。
- 两位女选手不能只靠低模五官区分：ChatGPT 保留蓝黑 bob 与青色发梢，Gemini 保留醒目的
  暖橙高马尾；开场放大立绘并明确标出“女将”，不改变两人的竞技装备与驾驶姿态。
- 队伍协作选角是并行操作面板，但沿用独立竞技的主视觉节奏：两侧各有可看清全身轮廓的
  2:3 主立绘卡、显著左右切换键、候选人轨道和确认按钮；桌面立绘宽度约 280-340 px，
  按可用高度缩放，不能把整侧做成不可读的满屏背景头像。
- 艇边库存菱形不能遮住角色；空中续航提示要上移并让出紧急飞行路线。
- 门柱相关失败统一说“撞柱”，方向和距离仅作为次级复盘证据。
- 六个常驻英文世界名牌已否决；只保留开场短身份互动。
- 玩梗 Logo 等用户提供正式 SVG 后再做，不生成占位 Logo，不常驻头顶。
- 立绘右下角 Gemini 水印清理属于独立资产编辑，不与本轮代码小修混做。
- 视觉是否达标只看真实桌面/横屏手机截图和人工评审；机器指标不能替代审美结论。
- 未来美术任务先做一项可见原型，用户确认方向后再扩展，连续两轮不达标立即停下讨论。
- 2026-09-12 拍板（覆盖 2026-08-22“露脸不立盔”及两条发型追拍记录）：车手头方案整体改为
  封闭式头盔。废弃 3D 面部五官、立绘裁切 Face Patch、发型骨骼蒙皮附件与 Tide GLB 弹簧骨头
  （H5 上表情/发型骨骼开销偏大，面部效果也不达标）。六款头盔纯外壳 + 反光面罩（烟熏底 +
  低阈值高光带），硬绑定 head 骨骼不做蒙皮；辨识度重点在后脑勺与侧面轮廓——圆润/尾翼导流/
  越野帽檐/棱角科技/空力尾椎/非对称双鳍六款轮廓，高饱和队色 + 高对比涂装，禁止同款换色。
  旧条目保留作历史，不再约束当前实现。
- 2026-09-16 拍板：performance 档海面恢复 0.4 泡沫碎化（uFoamBreakup，此前为 0）——
  手机海面整片平滑白纹读成 AI 水彩笔触，碎化后白帽碎成斑片；旗舰机由 severe 降档兜底，
  不再为弱机预设抹平海面。后续美术调整继续遵守“一项可见原型 → 用户确认 → 再扩展”。
- 2026-09-17 拍板：「身残志坚」喜剧字幕走竞品跳字范式（跑跑/QQ飞车/综艺花字：超粗展示字
  + 厚描边 + 高饱和填充 + 逐字 squash-stretch），落在本作漫画 HUD 语言上。字体定为毛笔
  （Ma Shan Zheng 马善政，OFL），原因是移动端安卓无系统楷体——自托管仅 4 字形的
  woff2 子集（约 2.3KB，随 CSS 内联），保证所有设备同一气势；系统楷体栈仅作加载前回落。
  布局拍板：身残占左侧电台卡下方空海、志坚占右侧飞控件上方，永不遮中央竞速视野。
- 2026-09-17 二次拍板（覆盖上一条布局与配色）：用户实机裁决边角黄字为 5 毛特效，改
  中央电影字幕卡——屏幕中轴横排题字（约 33% 高度带，警示横幅之下、船体投影之上），
  半透明羽化墨带底衬（峰值约 0.5 不透明度，竞速视线穿透），宣纸米白渐变填色 +
  暖金柔晕（废弃 #ffd23f 太阳黄与硬投影），逐字重砸（scale 3.4→0.9→1.08→1，
  stagger 0.14s）+「撞柱 · 大难不死」kicker + 右下朱红「命硬」印章；总时长 3.4s；
  双打整卡归该席半屏中轴。用户明确接受半透明中央字幕，"永不遮中央"让位于
  "半透明底衬不遮竞速视线"。
