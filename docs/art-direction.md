# Board Race 美术需求复盘

- 原始目标很简单：海面要有真实、汹涌、有尺度的大浪，而不是换成更绿、更亮的平面材质。
- 海面升级必须同时处理浪形、浪峰、船体起伏和水面接触；只调颜色、法线或闪点不算完成。
- 尾流不能是两条连续白轨；落水水花必须看得见；开场船体不能沉进动态浪面。
- 船体需要清楚的竞速轮廓、结构层次和速度感，不能只堆小零件。
- 选手需要更自然的重心、关节动作和比赛姿态，不能继续像僵硬卡通剪影。
- Gemini 电台不能重复，桌面和移动字幕都要居中、可读且不遮操作与航线。
- 艇边库存菱形不能遮住角色；空中续航提示要上移并让出紧急飞行路线。
- 门柱相关失败统一说“撞柱”，方向和距离仅作为次级复盘证据。
- 六个常驻英文世界名牌已否决；只保留开场短身份互动。
- 玩梗 Logo 等用户提供正式 SVG 后再做，不生成占位 Logo，不常驻头顶。
- 立绘右下角 Gemini 水印清理属于独立资产编辑，不与本轮代码小修混做。
- 视觉是否达标只看真实桌面/横屏手机截图和人工评审；机器指标不能替代审美结论。
- 未来美术任务先做一项可见原型，用户确认方向后再扩展，连续两轮不达标立即停下讨论。
