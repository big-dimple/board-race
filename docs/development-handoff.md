## 下一工作包:飞行提示卡重做 + 规则引导 + 雾道可读性

用户真机反馈(PC 为主,原文要点,逐条都是验收标准):

1. **时机好,形态差**:起飞 SPACE 与续飞提示的出现时机非常好;但按钮过大、不精致、
   色彩违和,与商业大作差距大。需要更小的键帽、更精致的排版与配色(对齐 PALETTE,
   与 HUD 视觉语言统一)。上轮已把键帽从固定盒改自适应,本轮继续收尺寸与打磨。
2. **每次都提示,熟手烦**:每次进入空道都弹提示。需要按熟练度/场次降频或静默
   (drivingCoach.mastery 已有类似机制,参考"一次会话最多一次"的电台技巧提示)。
   教学合同不变:不注入输入、不改物理、不增第二条路线。
3. **手机端缺漏**:该提示卡当前未给手机端做等价形态,属缺漏,需补齐
   (移动端现有「续」钮内规则文案,但起飞/续飞提示卡的呈现需确认对齐)。
4. **续飞提示字号**:手机端已 OK;PC 端文字仍然太小。
5. **蓝色字体黑色外框**:蓝字带一圈黑描边,视觉上像屏幕分辨率没调对的重影。
   检查 text-shadow/多层描边,去掉或改柔。
6. **规则误解导致流失(重点)**:漂移库存最多 3 格,但"一次飞行最多续飞一次"是规则;
   新玩家不知道,以为能空中接力 3 次,连按无效后判断为"按键失灵/bug 多/粗糙",
   无法理解难度设计,直接流失。引导目前没讲清"库存 3 ≠ 单飞可续 3"。
   需要在首飞路径上把这条规则讲透(桌面规则文案已有"本飞最多用 2 格 · 起飞 1 +
   续航 1",但显然没被读到/读懂——考虑更早、更显性的传达)。
7. **空中雾道(已诊断)**:白雾带太细、对海/天对比太低,读成"拖尾"而非"要跟随的航道";
   缺行进方向感、下一门位置与落水回收点的视觉锚。候选:加粗边缘、流动方向脉冲、
   门标塔提亮。按 art-direction 规则:先出一屏可见原型,用户确认方向后再扩展。
