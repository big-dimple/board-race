## 本轮改动(corridor 越界连续反馈)

起因:孩子反馈一碰航道边缘立刻死,无法接受。目标:"可飞空间—危险边缘—越界失控—失败"
连续反馈。旧模型 corridor 越界 0.35s 或累计 10m 位移即判负,是唯一"碰边即死"路径
(水面 off_course 本来就是警告+15s 宽限,未动)。

1. **判定模型**(course.ts):删除 0.35s/10m 双阈值,改为 danger∈[0,1] =
   max(越界深度/14m, 越界时间/1.8s),回线后 1.6 倍速衰减;danger≥1 判 corridor 负,
   语义不变。贴边擦碰有约 1.8s 回正窗口,深度 14m 硬边界仍即败。
2. **失控物理**(boat.ts `setCorridorDistress`,IBoat 新契约,每 fixed-step 重发布):
   风推离航道 3.5+11·L² m/s²(浅层可对抗,深层压过空控)、yaw/roll/pitch 阵风扰动、
   L>0.45 失速(额外阻力 + 目标高度下沉 2.8m)→ 不操作会物理跑飞,坠落先于判负发生。
3. **雾道视觉**(course.ts shader 新 uniform `uDistress`):墨缘横向 thrash、
   雾体撕裂孔洞、边缘红色脉冲告警着色、高频 alpha 闪烁;表现经 9/s 升 2.4/s 降平滑。
4. **表现层**:相机持续 rumble(`setDistress` 地板 0.32·L,reduced-motion 豁免);
   音频新增 corridor 风切带噪声(增益/频带随 L,事件性提示音非环境噪声)+ 分级警报 blip;
   HUD 复用 wrongway 横幅:阶段1"航道边缘 · 回到白雾内"/阶段2"失控下坠 · 立刻回正!",
   粗指针端缩小并左移避开续航提示卡;触觉 warning 分级(阶段2持续脉冲,0.9s 冷却节流)。
5. **harness**:新增 `corridor-storm` / `corridor-storm-deep` 截图场景(danger 0.3 / 0.55)。
