## 本轮改动 A:corridor 阶段事件化

1. **音频**(audio.ts `setCorridorDanger`):电影式警报 beeper——阶段1慢速单嘟
   (520Hz/0.62s),阶段2急促嘟嘟嘟(780Hz/0.27s);换档当帧重启发声;风切增益
   0.1+0.14·L²。
2. **触觉**(haptics.ts):新增 `storm-edge`(0.35/0.55)与 `storm-critical`(0.95/0.6 全马达)
   cue;新增 `setStorm(level)` 持续震感——弱马达嗡嗡随 L 升,失控档强马达加入,
   80ms 固定节拍重发;移动端 navigator.vibrate 同步分级。
3. **相机**(chaseCamera.ts):失控档持续 FOV 收紧(-1.5·deep);进入失控瞬间
   `stormKick()`(shake 0.34 + FOV -1.8 + 后拉)。
4. **视觉**:HUD 新增 `corridor-critical` 两侧红色脉冲受光条带(粗指针端减半宽);
   雾道 shader 加 `stormDeep` 第二曲线——失控档撕裂/闪烁/整道红脉冲大幅强于贴边档。
5. main.ts 统一按阶段跳变发事件(stage 0/1/2),不再按数值阈值。

## 本轮改动 B:车手立绘化重做

美术决策(对标 MK8/Wave Race:露脸保识别、浅色底+品牌色点缀、事件动画分层):

1. **去头盔露脸**(riderMesh.ts):肤色脸+眼睛+鼻梁,三种发型(short/bob/ponytail)
   按立绘锁定六人发色肤色(`DriverProfile.look`,racers.ts);赛服改白底+战队色
   手套/滚边+藏青侧片(旧版全身船色→"黑人机械臂"观感的根因)。Role 新增
   Skin/Hair,删 Visor;16 骨骼基线不变。
2. **挑衅**(rider.ts `taunt`):并肩(|along|<4.5m,侧向 1.6-7.5m,水面,>14m/s)
   触发,转头向对手+同侧挥拳 1.6s,每人 8s 冷却;main.ts 全对扫描触发,纯表现。
3. **看弯**:头部随 steer 预转 0.3rad(驱动层,庆祝/挑衅时抑制)。
4. **庆祝加强**:左手抬高 -1.6→-2.2、提前加入,冲线双手离把。
