# Board Race 开发交接

状态：第一站首次试玩阻塞已修复，等待玩家重新体验线上版本。

## 当前活动工作包

- 基线是已发布的三站协作提交 `9b36fc1`。玩家在共振接力进入蓝 / 黄圈后仍无法理解按键与时序。
- 根因是右席能力键没有右 Shift、脉冲存在隐藏接收窗口、泊位不抑制惯性，且 HUD 只用小字显示按键。
- 现改为两席各自蓄能：左席 `Left Shift`，右席 `Right Shift / K / Numpad0`；接收端可提前锁定，
  投递完成后自动传输。有效泊位内按住能力键会帮助船体停稳。
- 第一站入口和半屏 HUD 直接显示蓝 / 黄圈、精确按键、当前拍与各席蓄能进度。

## 遗留实机项

- 仍需玩家确认右 Shift 在其实际键盘布局上顺手；`K` 与小键盘 `0` 保留为备用。
- 自动化覆盖标准 Gamepad API，但仍需两只实体手柄确认 RT/LT 行程、X 持续能力、Start 暂停和震动。
