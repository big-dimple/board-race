# Board Race 开发交接

状态：单摇杆协作驾驶、机械工位引导与统一选角视觉完成，等待发布后的两名玩家实体手柄试玩。

## 当前活动工作包

- 第一站从蓝 / 黄点蓄能改为“锚锤工坊”：锚钉手压钉、合拢夹爪并稳定轨道，冲击锤手抬锤、
  落锤并发射实体核心；两次后交换工具。
- 核心、机械轨道、冲击锤、锚钉机和接收夹爪由判定状态直接驱动。锚定不足时核心偏落入水、
  触发对应席位的声音 / 震动 / HUD 原因，再在当前拍复位。
- 双锁水闸补齐可转动绞盘、钢索、宽水闸和终端夹具；水空协奏补齐控制轮、供能线与发射架。
- 蓝 / 黄工作区半径和箭头已放大。正式工位接通能力后使用真实速度上的弹簧阻尼锚泊，教学区
  只消散已有惯性，不会拉动未操作的另一艘船。
- 手柄协作移动统一为一根左摇杆：X 轴转向、Y 轴前进 / 制动倒车，斜向同时生效；十字键仅作数字输入备用，RT / LT 不参与移动，HUD 只显示左摇杆。
- 工位视觉与状态共用一条数据链：机器之间有流动能量节点和连线，蓄力有压力表 / 活塞，锚定有卷筒 / 夹爪，水闸有棘轮 / 钢索，飞行台有屏幕 / 信标；HUD 会用动态键帽指向当前责任。
- 双席选角沿用独立竞技的主视觉层级：左右各有 2:3 大立绘、信息列、六人候选轨道、方向切换键和显著确认锁定反馈；设备与屏幕所有权仍在入座时固定。

## 遗留实机项

- 自动化覆盖标准 Gamepad API，但实体手柄的摇杆回中死区、斜向同时输入、X 长按、Start 暂停和震动强度
  仍需两席玩家一起确认。
- 程序化机械道具已达到可试玩辨识度，后续美术替换不得改变锤击、锚定、绞盘和飞行门的状态真相。

## 唯一下一步

- 发布后由两名玩家使用实体手柄从“重玩驾驶校准”进入，完整完成锚锤工坊和第一道水闸；只记录
  哪个实体动作看不懂、哪个按键不顺手、以及是否仍会被浪推出工位，再据此做一轮玩法取舍。
